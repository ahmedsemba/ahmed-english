# الفصل التفاعلي — إعداد خدمة الصوت

هذا المجلد يحتوي على Worker تجريبي لإصدار رموز LiveKit. لا توجد مفاتيح أو أسرار فعلية داخل GitHub.

## الخدمات المطلوبة
1. مشروع LiveKit Cloud للحصول على WebSocket URL وAPI Key وAPI Secret.
2. Cloudflare Worker مع KV namespace باسم `CLASSROOMS` مربوط بالـWorker بالاسم نفسه.
3. ضبط Secrets في إعدادات Worker:
   - `LIVEKIT_URL`
   - `LIVEKIT_API_KEY`
   - `LIVEKIT_API_SECRET`
   - `TEACHER_PIN` (رمز طويل وفريد يحتفظ به المدرس فقط)

## نقاط الحماية في هذا النموذج
- لا يتم إرسال LiveKit API Secret إلى المتصفح.
- رمز المدرس الخاص بكل غرفة يُنشأ عشوائيًا، ويُخزن بصمة SHA-256 فقط.
- الطالب يحصل على صلاحية الصوت والاستماع، لكن لا يحصل على صلاحية إرسال بيانات السبورة.
- المدرس وحده يستطيع إرسال بيانات الصفحة والرسم وإنهاء غرفته.
- الغرف تنتهي تلقائيًا بعد أربع ساعات.
- يُقبل الاتصال من نطاق GitHub Pages المحدد في الكود فقط.

## نقاط لم تكتمل بعد
- هذا Worker لم يُنشر أو يُختبر على حساب Cloudflare فعلي.
- رمز المدرس العام `TEACHER_PIN` ما زال وسيلة بدء مؤقتة؛ الأفضل لاحقًا ربط إنشاء الغرفة بتسجيل دخول Firebase Auth للمدرس.
- يجب تفعيل حدود استخدام ومراقبة قبل تشغيل حصص حقيقية.
- تحميل PDF من Google Drive يتم حاليًا عبر المسار التجريبي `/pdf` للملفات العامة التي تسمح بالمشاهدة عبر الرابط؛ لا يدعم الملفات الخاصة.
- واجهة الاختبار مربوطة برمجيًا بـLiveKit ومزامنة PDF والكتابة، لكن لم يتم اختبار الاتصال الفعلي بعد.

## اختبار الصحة
بعد النشر وإضافة الأسرار والـKV، افتح:
`https://YOUR-WORKER.workers.dev/health`
ويجب أن تظهر `configured: true`.

لا تضع أي Secret في ملفات GitHub أو ترسله في المحادثات.


## واجهة العميل التجريبية
- صفحة `classroom-demo.html` تستخدم LiveKit JS SDK من CDN الرسمي.
- المدرس ينشئ غرفة، ويشارك رقم الحصة ورمز الدخول مع الطالب.
- كل مشارك يفعّل الميكروفون من المتصفح بعد منح الإذن.
- المدرس وحده يرسل تحديثات الصفحة والكتابة؛ الطالب يستقبلها بوضع مشاهدة فقط.
- الطالب يحصل على معرّف الملزمة من بيانات الحصة، ثم يحمّل نفس PDF من Google Drive عبر Worker قبل الاتصال.
- يجب إدخال رابط Worker بعد نشره في واجهة الاختبار. لا يوجد رابط Worker منشور حتى الآن.

## ملاحظات قبل اختبار الجهازين
1. انشر Worker في حساب Cloudflare واربط KV واضبط الأسرار من لوحة التحكم فقط.
2. استخدم نطاق GitHub Pages المسموح في `ALLOWED_ORIGIN`. إذا كان الموقع يستخدم نطاقًا مخصصًا، يجب تعديل هذا النطاق في Worker قبل الاختبار.
3. اختبر الصوت والاتصال والصفحات على جهازين بعد إعداد الخدمة. فحص JavaScript هنا لا يثبت نجاح الاتصال الحقيقي.
4. لا تستخدمه مع طلاب فعليين قبل إضافة مصادقة مدرس مرتبطة بحسابات المنصة، وحدود طلبات، واختبار الخصوصية والأمان.


## تحميل ملزمة موجودة في قسم الملازم
- صفحة الاختبار تقرأ قائمة `materials` الموجودة بالفعل في Firestore وتعرض روابط Google Drive الصالحة في قائمة اختيار.
- عند اختيار الملزمة، تحاول الصفحة تحميل ملف PDF عبر Google Drive API ثم عرضه في PDF.js؛ لا يتم نسخ الملف إلى خدمة تخزين أخرى.
- الواجهة تعرض روابط Google Drive المخزنة بالفعل في قسم الملازم، وتستخرج معرّف الملف من رابط المشاركة.
- مسار تنزيل PDF الحالي مجرد محاولة أولية باستخدام API key للملفات العامة؛ لم يتم اختباره على ملف حقيقي، ولا ينبغي اعتباره تكاملًا مكتملًا.
- توثيق Google الرسمي يوضح أن تنزيل محتوى الملفات عبر `files.get?alt=media` يحتاج OAuth access token بنطاق يسمح بقراءة محتوى الملف. لذلك قد نحتاج إكمال Google OAuth / Picker، خصوصًا للملفات الخاصة أو المقيدة.
- لا تضع OAuth Client Secret أو Service Account key في الصفحة أو GitHub. أي API key يستخدم في المتصفح يجب تقييده بالموقع وبـGoogle Drive API.
- يبقى اختيار PDF من الجهاز متاحًا كحل اختبار مؤقت حتى نتأكد من مسار صلاحيات Drive الصحيح.


## اختيار ملزمة الحصة تلقائيًا من قسم الملازم
- صفحة الفصل تقرأ نفس مجموعة Firestore المسماة `materials` التي يستخدمها تبويب الملازم المجانية ولوحة المدرس.
- يختار المدرس الصف الدراسي أولًا، ثم تظهر له ملازم هذا الصف والملازم المحددة `للكل`.
- عند إنشاء الحصة، يحفظ Worker معرّف الملزمة والصف ضمن بيانات الغرفة المؤقتة.
- عند دخول الطالب، يعيد Worker بيانات الملزمة المرتبطة بالحصة، وتحمّل صفحة الطالب نفس PDF تلقائيًا قبل الاتصال؛ لذلك لا يحتاج الطالب لاختيار الملف أو فتح نسخة محلية.
- أضيف المسار `GET /pdf?fileId=...` ليجلب PDF عام المشاركة من Google Drive ويعيد بثه مباشرة إلى PDF.js. لا يحتفظ Worker بنسخة من الملف ولا ينقله إلى تخزين آخر.
- يجب أن يكون رابط Drive متاحًا بصلاحية «أي شخص لديه الرابط - مشاهد». حد العرض التجريبي 40 ميجابايت. بعض الملفات الكبيرة قد يعرض Drive لها صفحة تأكيد تنزيل بدل PDF؛ في هذه الحالة سيظهر تنبيه واضح ولن يفتح الملف داخل الفصل.
- هذا المسار لا يستخدم OAuth لأنه يقتصر على الملفات العامة التي يتيحها رابط المشاركة. لا تستخدمه لملفات خاصة أو ملفات تحتوي بيانات حساسة.
- لم يتم اختبار تنزيل ملف حقيقي من حساب Drive بعد، كما أن Worker غير منشور حتى الآن. يجب اختبار ملف صغير عام أولًا بعد النشر.
