# الفصل التفاعلي — إعداد خدمة الصوت

هذا المجلد يحتوي على Worker تجريبي لإصدار رموز LiveKit. لا توجد مفاتيح أو أسرار فعلية داخل GitHub.

## الخدمات المطلوبة
1. مشروع LiveKit Cloud للحصول على WebSocket URL وAPI Key وAPI Secret.
2. Cloudflare Worker مع KV namespace باسم `CLASSROOMS` مربوط بالـWorker بالاسم نفسه.
3. ضبط Secrets في إعدادات Worker:
   - `LIVEKIT_URL`
   - `LIVEKIT_API_KEY`
   - `LIVEKIT_API_SECRET`
   - `TEACHER_PIN` (رمز طويل وفريد يحتفظ به المدرس فقط)

## نقاط الحماية في هذا النموذج
- لا يتم إرسال LiveKit API Secret إلى المتصفح.
- رمز المدرس الخاص بكل غرفة يُنشأ عشوائيًا، ويُخزن بصمة SHA-256 فقط.
- الطالب يحصل على صلاحية الصوت والاستماع، لكن لا يحصل على صلاحية إرسال بيانات السبورة.
- المدرس وحده يستطيع إرسال بيانات الصفحة والرسم وإنهاء غرفته.
- الغرف تنتهي تلقائيًا بعد أربع ساعات.
- يُقبل الاتصال من نطاق GitHub Pages المحدد في الكود فقط.

## نقاط لم تكتمل بعد
- هذا Worker لم يُنشر أو يُختبر على حساب Cloudflare فعلي.
- رمز المدرس العام `TEACHER_PIN` ما زال وسيلة بدء مؤقتة؛ الأفضل لاحقًا ربط إنشاء الغرفة بتسجيل دخول Firebase Auth للمدرس.
- يجب تفعيل حدود استخدام ومراقبة قبل تشغيل حصص حقيقية.
- اختيار ملفات Google Drive يحتاج تكامل Drive API / OAuth؛ لا نعتبر رابط مشاركة Drive وحده كافيًا لضمان عمل PDF.js.
- لم يتم ربط LiveKit أو مزامنة PDF والكتابة في واجهة المنصة بعد.

## اختبار الصحة
بعد النشر وإضافة الأسرار والـKV، افتح:
`https://YOUR-WORKER.workers.dev/health`
ويجب أن تظهر `configured: true`.

لا تضع أي Secret في ملفات GitHub أو ترسله في المحادثات.
