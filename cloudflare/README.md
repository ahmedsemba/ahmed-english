# إعداد الفصل الصوتي داخل منصة مستر أحمد

هذا المجلد يحتوي على خادم إصدار رموز الدخول (tokens) للفصل الصوتي. لا تضع مفاتيح LiveKit أو رمز المدرس في ملفات GitHub أو داخل كود المنصة.

## المطلوب قبل التشغيل

1. إنشاء مشروع LiveKit Cloud على خطة Build المجانية.
2. من المشروع انسخ:
   - عنوان الخادم WebSocket، ويبدأ عادةً بـ `wss://`
   - API Key
   - API Secret
3. إنشاء حساب Cloudflare مجاني.

## نشر خادم إصدار الرموز

1. افتح Cloudflare Dashboard ثم Workers & Pages وأنشئ Worker جديدًا.
2. انسخ محتوى الملف `voice-worker.js` بالكامل إلى محرر الـWorker ثم احفظ وانشر.
3. أنشئ KV namespace باسم `CLASSROOMS`، ثم اربطه بالـWorker بنفس الاسم كـBinding.
4. في إعدادات الـWorker، أضف المتغيرات/الأسرار التالية:
   - `LIVEKIT_URL` = عنوان LiveKit الذي يبدأ بـ `wss://`
   - `LIVEKIT_API_KEY` = مفتاح API
   - `LIVEKIT_API_SECRET` = السر الخاص بـ API
   - `TEACHER_PIN` = رمز سري جديد تختاره أنت، ولا تشاركه مع الطلاب
5. أعد نشر الـWorker.
6. افتح رابط الـWorker وأضف `/health`. يجب أن تظهر `"configured": true`.

## تشغيل الفصل

1. افتح لوحة المستر في المنصة.
2. الصق رابط الـWorker المنشور في خانة «رابط خادم الصوت».
3. اكتب رمز المدرس السري الذي وضعته في `TEACHER_PIN`.
4. اكتب عنوان الحصة واختر الصف واضغط «بدء الحصة والاتصال بالصوت».
5. الطالب المسجل في الصف المحدد سيدخل من زر «دخول الحصة» في حسابه. يبدأ ميكروفون الطالب مغلقًا ويمكنه تشغيله عند الحاجة.
6. الصق رابط Google Drive للملزمة واضغط «عرض الملزمة للطلاب». تنقل الصفحات والكتابة على السبورة تتزامن عبر Firestore.

## ملاحظات مهمة

- لا تنشر `LIVEKIT_API_SECRET` أو `TEACHER_PIN` في GitHub أو ترسلهما في محادثة.
- رمز المدرس لا يُحفظ في المتصفح؛ اكتبه عند بدء الحصة وإنهائها.
- روابط الحصص ورموز دخولها مؤقتة، وتنتهي صلاحية سجل الغرفة بعد 4 ساعات كحد أقصى.
- هذا الإصدار يحتاج تجربة فعلية على موبايل المدرس وموبايل طالب قبل نقله إلى الفرع الرئيسي.
- استخدام LiveKit Cloud المجاني محدود بعدد دقائق اتصال المشاركين وحجم نقل البيانات؛ راجع لوحة الاستخدام قبل الاعتماد عليه في جدول حصص منتظم.
- لا يُسجل هذا الإصدار صوت الحصة ولا يستخدم الكاميرا.
